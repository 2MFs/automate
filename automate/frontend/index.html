How autoMate works

        

          autoMate is a small server running on your machine. It exposes a
          unified entry point that any LLM can call. When you (or an upstream
          model like Claude Code) hand it a natural-language request, it
          plans, picks the right tool, and runs it locally.

Use it on your phone

        

          autoMate's UI is a Progressive Web App — it installs on Android and
          iOS without an app store. The phone is the controller; the
          actual hub keeps running on your computer (a phone can't run shell
          commands or drive a real browser).
        

        
    
          
  1. On your computer, restart the hub on your LAN: stop the running process, then run automate serve --host 0.0.0.0 (or set AUTOMATE_HOST=0.0.0.0).
    2. 
          
  2. Find the computer's LAN IP (macOS: System Settings → Network · Windows: ipconfig · Linux: ip addr).
    3. 
          
  3. On your phone (same WiFi), open Chrome/Safari at http://<your-ip>:8765.
    4. 
          
  4. Phone menu → Add to Home Screen. Boom — autoMate is now an app.
    5. 
        

        

          ⚠ --host 0.0.0.0 exposes the hub to anyone on your LAN.
          Don't do this on coffee-shop WiFi. For internet-wide access, use the
          relay (see below) instead of opening a port.

Use it from anywhere (relay)

        

          Don't want to expose your laptop on the internet, but still want your
          phone (or a remote AI) to reach your hub? autoMate ships with a
          relay client: the hub dials out to a relay server,
          opening a reverse tunnel. The phone hits the relay's HTTPS URL — the
          relay forwards over the tunnel to your hub.
        

        
automate relay wss://relay.example.com/tunnel --token YOUR_TOKEN

        

          The protocol is implemented in automate.relay;
          a public hosted relay is not yet open. See
          docs/relay.md
          for the protocol if you want to self-host.
        

      


      
      

        
Privacy & safety

        
    
          
  • Server binds to 127.0.0.1 only — not reachable from the network.
    • 
          
  • API keys and OAuth tokens are encrypted with Fernet; the symmetric key lives at ~/.automate/secret.key (chmod 600).
    • 
          
  • The LLM call goes directly from autoMate to the provider you chose. Nothing else sees it.
    • 
          
  • Heads-up: shell.exec and script.run run with the autoMate process's full privileges. Treat it like any other automation tool — only run prompts you'd run yourself.
